# Bahan masukan

Taruh di folder ini bahan mentah tentang produk, misalnya:
- catatan;
- dokumen dari ChatGPT atau dari rapat;
- contoh berkas, tangkapan layar, dan spreadsheet.

`/tiket:rencanakan-produk` membaca bahan-bahan ini untuk menyusun PRD, glosarium, dan keputusan terbuka.

Isi folder ini bukan aturan. Yang berlaku hanya yang sudah masuk ke `docs/PRD.md`. Jangan menaruh data pribadi asli di sini.
