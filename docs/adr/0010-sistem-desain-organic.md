# Sistem desain "Organic", diadaptasi untuk dashboard, hanya mode terang

Status: accepted (2026-10-08) — pilihan pemilik

Pemilik memilih gaya *Organic / Natural* (designprompts.dev). Sumbernya ditulis untuk landing page, sehingga diadaptasi menjadi dua zona: *zona suasana* memakai ciri khasnya penuh (blob, radius asimetris, gerak scale), sedangkan *zona kerja* menjaga kepadatan dan keterbacaan angka. Beberapa token warna sumber tidak memenuhi kontras WCAG AA untuk teks dan bingkai input, sehingga diganti dengan varian yang lebih tua. Varian aslinya hanya dipakai untuk dekorasi. Aplikasi hanya punya mode terang: sumbernya satu palet, dan mode gelap akan menggandakan pekerjaan uji kontras tanpa diminta. Acuan lengkap: `docs/DESIGN.md`.
